# twitch-streamer-growth-analysis

# Problem Statement

What factors separate Twitch channels that sustain or grow their viewership from those that stagnate or decline, and can we identify early signals of a channel's trajectory?

This project combines streamer-level data with game-category trend data to explore:

1.Does streaming consistency correlate with higher peak/average viewers or follower growth?
2.Do certain game categories systematically drive more viewership, or is it dominated by a few top channels?
3.Is there a relationship between average viewers and follower growth rate?
4.Are there outlier channels that break expected patterns and what explains them?

# Data Sources
-Top Streamers on Twitch — top 1000 streamers (followers, watch time, avg/peak viewers, partnership status, language)
-Evolution of Top Games on Twitch (2016–2021) — monthly game-level trends (hours watched, hours streamed, avg/peak viewers.
